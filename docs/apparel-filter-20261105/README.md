## 规则

- 查看全部来源品类字段 `category_l1/category_l2/category/categories`，保留原文。品类完整标签或路径段命中服饰、服装、鞋、箱包、内衣、家居服即排除；睡衣/睡袍/浴袍、运动鞋/拖鞋、双肩包/单肩包/胸包/小背包/背包、旅行箱/行李箱/登机箱作为这些品类的来源叶子标签。
- 明确家电/数码、摄影配件，以及水杯/清洁剂等非服饰品类证据优先保护来源误标冲突；含/赠睡衣、睡袍、浴袍、家居服或内衣的组合描述保留。这是“不得误伤家电”和“含睡衣套装不是服饰”的通用规则，不是按 ID 放行。
- 无品类命中时按请求名称词兜底：睡衣、睡袍、浴袍、家居服、内衣、T恤、衬衫、卫衣、外套、西裤、西装、连衣裙、袜、鞋、拖鞋、帽、围巾、背包、行李箱。家电/数码保护同样生效。
- 在共享 finalizer 中服务之后、配件之前执行。只从发布视图中排除，完整原始商品档案落 `archive/apparel.json`，每次重放、重新判定；不删除源数据、不依赖旧 goods-excluded 作为输入。
- 每条 `excluded_reason=apparel`；`matched_rule=category|name`、`matched_text` 既在顶层又在 `exclusion` 内。meta 按主理由汇总 `excluded_by_rule.apparel`，匹配方式不会混成业务规则计数。
