# 富士相机调研（2026-10-27）

> 范围：仅富士 X 系列相机——可换镜机身（X-H / X-T / X-S / X-Pro / X-E / X-M）、固定镜头机（X100 / X half），以及官方套机。不含 GFX、instax、镜头单卖、配件、耗材、打印/医疗/工业产品。机身与套机一行一条。
>
> 方法：只访问公开页面/公开接口；不登录、不绕验证码、不逆向 App。正式取证阶段（日志 96 次）同 host 串行、并发 1、相邻请求 ≥2.15 秒；首轮 14 次人工侦察在限速脚本建立前，未严格套用该间隔（首页/robots 曾连续 2 次），发现后改为脚本限速；另有 3 次补充核验按 2.2 秒间隔执行。合计约 113 次（≤200），未触发 429/412/验证码。证据见 [`富士相机调研-20261027-evidence/`](富士相机调研-20261027-evidence/README.md)。

## 一、结论先行

1. **能接，但只能接“机型档案”：名称、型号、主图、规格、官方 URL 可免登录稳定拿到**；当前线 9 台可换镜机身 + 2 台固定镜头，实测 13 种套机版本，规格页 37–48 个条目。
2. **不能接“官方人民币价”**：富士中国官网不标人民币价；中国频道只有海外 USD 起价；天猫官方旗舰店 302 到登录页；京东自营/官方授权旗舰店商品页 200，但价格写的是“登录查看价格”。
3. **建议接入方式**：先建“富士相机机型档案（无价）”，机身/套机分 id，价格字段留空并标注“暂无官方人民币价”；不要用第三方价冒充官方价。
4. **如果业务硬性要求“官方人民币价”才能上线，本轮结论是：不建议接**。价格不是抓取难度问题，而是官方匿名页面根本不公开。

## 二、六个问题逐项回答

### 2.1 有没有免登录可用的公开页面/接口？

有，但分成两层：**富士中国官网负责“名录/入口”，富士 X 全球站的中国频道负责“产品页/规格页”**。两者都免登录，raw HTTP 可读，不需要浏览器。

| 页面 | 用途 | HTTP | 关键结论 |
|---|---|---:|---|
| `https://www.fujifilm.com.cn/cn/zh-hans/consumer/digitalcameras/X` | X 系列名录 | 200 | 可换镜 10 款 + 固定镜头 3 款（含旧款）；只给卡片和“了解详情”外链 |
| `https://www.fujifilm.com.cn/cn/sitemap.xml` | 枚举/改版监测 | 200 | 1222 条 URL；X 系列页 `lastmod=2026-09-04` |
| `http://www.fujifilm-x.com/zh-cn/products/cameras/x-t5/` | 产品页 | 200 | 名称、主图、发布日、USD 参考价；无人民币价 |
| `http://www.fujifilm-x.com/zh-cn/products/cameras/x-t5/specifications/` | 规格页 | 200 | HTML 表格，47 个顶层条目 |
| `http://www.fujifilm-x.com/zh-cn/products/cameras/x-e5/specifications/` | 新规格页 | 200 | 改为 `div + h6`，46 个条目；标签仍是英文 |
| `https://www.fujifilm.com.cn/cn/zh-hans/consumer/digitalcameras/e-Shop` | 官方“网上商城”入口 | 200 | 只列京东/天猫/苏宁/授权店链接，**页面本身不标价** |
| `https://sp.fujifilm.com.cn/shops/ecshop` | 官方授权网络店 | 200 | 官方给出天猫/京东/苏宁旗舰店入口 |
| `https://fujifilm.tmall.com/` | 天猫官方旗舰店 | **302** | 跳 `login.taobao.com`，匿名不可读 |
| `https://item.m.jd.com/product/100104023155.html` | 京东自营 X-T5 套机 | 200 | 有名称/主图/版本，价格被登录门遮住 |
| `https://so.m.jd.com/ware/search.action?...` | 京东搜索 | **302** | 跳 `risk_handler` 风控页，立即停止 |

需要注意的 HTTP 细节：

- `https://fujifilm-x.com/...`（顶点域）会 **301 到 `http://www.fujifilm-x.com/...`**，是协议降级；抓取用 `http://www` 最稳。`https://www` 多数页可用，但 X100V 规格页会 403，不能假设 HTTPS 一定更好。
- X100V 的 `/specifications/` 返回 **301 到产品页**；同一路径的 HTTPS 变体返回 **403 Cloudflare `Just a moment...`**。旧款页面行为不一致，不能假设“所有规格页都 200”。
- 京东 PC 商品页 `item.jd.com` 返回 35KB 的 SPA 空壳，正文无商品数据；`item.m.jd.com` 才是服务端渲染页。

### 2.3 价格到底有没有官方标价？

**没有可匿名读取的官方人民币价。** 分四层说清楚：

| 渠道 | 是否标人民币价 | 是否免登录可读 | 证据 |
|---|---|---|---|
| 富士中国官网 `fujifilm.com.cn` 产品/系列页 | **否** | 是（但本来就没价） | X 系列页只有卡片和参数入口，无价格字段 |
| 富士中国官网“网上商城” `.../digitalcameras/e-Shop` | **否** | 是 | 200；只列京东/天猫/苏宁/授权店入口，不标价 |
| 富士 X 中国频道 `fujifilm-x.com/zh-cn` | **否**；只有 USD | 是 | X-T5 JSON-LD：`lowPrice=1699`、`priceCurrency=USD`、`Starting from US$1,699 (excluding VAT). Prices may vary by region.` |
| 天猫“富士官方旗舰店” | 平台价，非官网价 | **否** | 302 → `login.taobao.com` |
| 京东“富士京东自营旗舰店”/“富士影像旗舰店” | 平台价，非官网价 | **否** | 商品页 200，但 `priceLoginText=登录查看价格`，价格字段被掩码（如 `1??90`） |

补充事实：

- 12 个样本产品页里，**7 个**有 USD `lowPrice`（X-H2S 2,499 / X-H2 1,999 / X-T5 1,699 / X-S20 1,299 / X-T50 1,399 / X-M5 799 / X100VI 1,599），**0 个**有 CNY/RMB/人民币/¥。
- 另外 5 个（X-Pro3、X-T30 III、X-E5、X half、X100V）连 USD 报价都没有；X100V 页面明确 `Discontinued`。
- **没有找到“官方建议零售价（人民币）”**。本轮只抽查了新闻列表首页，没有逐条翻新闻稿；商品页/规格页确实没有人民币价。本轮不把海外 USD 换算成人民币，也不把 USD 说成中国价。
- **第三方价**：本轮没有把 ZOL/京东搜索的第三方价格写进官方价字段。京东搜索一次即触发风控；ZOL 搜索返回 GBK 页面且结果与关键词不匹配。若后续确实需要第三方价，必须单独字段 `reference_price`，带来源 URL、抓取时间、是否促销、不可当官方价——本轮不采用。

**结论**：价格是富士这条线最大、也最致命的缺口。不是“再加个解析”能解决，而是官方匿名页面没有这个数据。

### 2.4 身份标识：没有 CP 料号，用什么做稳定 id？

用 **“官方型号 slug + 机身/套机后缀”**，不用商品标题。规则见第三节。

### 2.5 参数结构化程度：文字表格还是图片？

**是 HTML，不是图片**，但有两套结构，必须都支持：

| 形态 | 适用型号（样本） | 结构 | 规格条目数 | 8 个关键字段命中 |
|---|---|---|---:|---|
| TablePress 表格 | X-H2S / X-H2 / X-Pro3 / X-T5 / X-S20 / X100VI / X100V | `<table id="tablepress-...">`，`td` 三列 | 43–48 | 8/8（机身），7/7（固定镜头，卡口不适用） |
| `div + h6` | X-T50 / X-T30 III / X-E5 / X-M5 / X half | `.camera-specifications__block`，`h6` 标签 + 值 | 37–46 | 7/8；X half 6/7 |

实测 5 台机身的字段数（8 个关键字段：型号、卡口、传感器、像素、连拍、视频、重量、电池）：

| 型号 | 规格条目 | 形态 | 命中 | 实际拿到的关键值（节选） |
|---|---:|---|---:|---|
| X-H2S | 46 | table | 8/8 | APS-C 23.5×15.6mm X-Trans CMOS 5 HS；2616 万；X 卡口；NP-W235；约 660g（含电池/卡） |
| X-T5 | 47 | table | 8/8 | APS-C 23.5×15.7mm X-Trans CMOS 5 HR；4020 万；X 卡口；NP-W235；约 557g |
| X-S20 | 44 | table | 8/8 | APS-C 23.5×15.6mm X-Trans CMOS 4；26.1M；X 卡口；NP-W235；约 491g |
| X-T50 | 45 | div | **7/8** | APS-C 23.5×15.7mm X-Trans CMOS 5 HR；40.2M；X 卡口；NP-W126S；约 438g；**无顶层“连拍”字段** |
| X-E5 | 46 | div | **7/8** | APS-C 23.5×15.7mm X-Trans CMOS 5 HR；40.2M；X 卡口；NP-W126S；约 445g；**无顶层“连拍”字段** |

能稳定解析的字段：**传感器画幅、有效像素、卡口、视频、重量、电池型号**；连拍在旧表里完整，在新 `div` 页里没有顶层字段（部分信息藏在 Drive Mode 里），需要单独补规则或人工校验。

解析时还要处理三个脏点：

1. **语言不一致**：`zh-cn` 页面大量标签/值是英文（`Model Name`、`Number Of Effective Pixels`、`26.1 millions pixels`），旧页是中文（`机型`、`2616万像素`）。必须做双语标签映射。
2. **单位不一致**：`万像素` vs `millions pixels`；重量有“含电池和存储卡/不含”两段；电池有 `NP-W235锂电池（附带）` 与 `NP-W126S Li-ion battery (included)`。
3. **嵌套块**：新页的 `Movie Recording`、`Power Supply` 是三层嵌套，直接按 `div` 切会拿到空值；要按 DOM 父子关系取文本。X-T50 的 `Power Supply` 里还嵌了续航子表。

### 2.6 规模：在售机身 + 套机大约多少条？

先区分几个口径，避免把“官网在列”说成“中国在售”：

| 口径 | 数量 | 说明 |
|---|---:|---|
| 官网 X 系列页“在列” | **13** | 可换镜 10 + 固定镜头 3；含旧款 X-E4、X100V |
| 当前线（规格页导航） | **11** | 可换镜 9 + 固定镜头 2；不含 X-E4、X100V |
| 实测套机版本 | **13 种** | 来自 5 条机身线：X-H2 / X-T5 / X-S20 / X-T50 / X-E5 |
| 套机 SKU（仅官方颜色，不含套餐/随机发货） | **24 个** | 1 + 8 + 4 + 9 + 2 |
| 机型 × 版本条目（当前线，不含颜色） | **24 条** | 11 机身 + 13 套机 |
| 含旧款的条目 | **26 条** | 13 机身 + 13 套机 |

> “当前线”只表示官网规格页导航仍收录，不等于中国库存/在售；X-Pro3 是 2019 年机型，实际库存需另核。本文不把 `schema.org/InStock` 当作中国在售证据。

枚举方式（可复跑）：

1. **名录**：`fujifilm.com.cn/.../digitalcameras/X` 页面卡片，按 `headline :lv="4"` 取 `FUJIFILM X-*`；X 系列页同时混排列旧款，需再用规格页导航过滤。
2. **当前线**：任一规格页左侧导航，X 线为 `x-h2s / x-h2 / x-pro3 / x-t5 / x-s20 / x-t50 / x-t30-iii / x-e5 / x-m5 / x100vi / x-hf1`，共 11 个。

4. **未枚举到的**：X-M5、X-T30 III 的套机没有在本次公开页里抓到；不猜、不凑数。按已实测口径，规模是 **24 条（当前线）/ 26 条（含旧款）**，不是“大概几十条”。

### 2.7 风险：条款、反爬、图片、改版

**条款/robots**

- `fujifilm.com.cn/robots.txt`：产品页未被 Disallow；**禁止 `/cn/search/`、登录/注册路径**。本轮不碰。
- `fujifilm-x.com/robots.txt`：只禁 `/wp-admin/`、`/wp-login.php`；对搜索/AI bot 有 `Crawl-delay 1/5/10/60`，对 `*` 没有明确 crawl-delay。我们仍按 ≥2.15 秒自限。
- 京东 `robots.txt` 302 回首页，等于没有可读规则；天猫/京东的登录与风控条款优先，**不要用账号/验证码去“解决”价格**。

**反爬实测**

| 站点 | 现象 | 判断 |
|---|---|---|
| `fujifilm.com.cn` | 直连 200，无验证码 | 低风险，低频可采 |
| `fujifilm-x.com` | Cloudflare；顶点 HTTPS 301→HTTP；X100V HTTPS 规格页 403 `Just a moment...` | 中风险；用 `http://www`、单页低频、遇到 403 停 |
| 天猫 | 302 → `login.taobao.com` | 高；匿名不可读 |
| 京东商品页 | 200，但价格 `登录查看价格`；PC 页 SPA 空壳 | 中高；可拿名称/图/版本，拿不到价 |
| 京东搜索 | 302 → `risk_handler` | 高；一次即触发，**不要重试** |
| 京东套机 SKU 直链 | 302 → `risk_handler`（`evApi=color-mesh_A_SC_mview_show`） | 高；连续 3 个 SKU 直链即触发，套机读父页版本矩阵 |
| 图片 CDN | 200，`image/jpeg`，`Access-Control-Allow-Origin: *`，缓存 30 天 | 技术可取，但版权仍归富士 |

**图片版权/热链**

- 官方图 CDN 匿名可取，且 CORS 全开；但“能热链”不等于“可商用”。建议**下载后存自己的对象存储**，加来源与版权字段，不要长期热链。
- 京东图 CDN 同样匿名 200；套机图与机身图可能不是同一张，入参要区分。

**页面改版**

- 没有构建号。可用信号：`Last-Modified`（如 X-E5 产品页 `2025-06-16`）、`X-Post-Shield: allowed-known-slug`、`Cache-Control: max-age=604800`、静态资源 `?ver=1.5`、sitemap `lastmod`（X 系列页 2026-09-04；X-HF1 支持页 2026-09-30）。
- **最大的改版风险是规格页结构换代**：2022–2023 机型用 TablePress 表格，2024–2025 机型改用 `div + h6`，且标签英文化。解析器必须双形态；只写一种，下一代机型就会漏。
- 建议每周/每月一次全量校验：规格条目数、8 个关键字段是否存在、型号 slug 是否 301/404。数量突变就告警。
- **套机不要逐个 SKU 直链抓**：本次对 3 个套机 SKU 直链（`100038651631`/`100046206061`/`10170879177339`）连续请求，全部 302 到 `risk_handler`；正确做法是读父商品页内嵌的 `newColorSize` 版本矩阵。

## 三、身份 id 规则（可复跑）

### 3.1 主键

```
fujifilm/{model-slug}/{variant}
```

- `model-slug`：官方型号去掉 `FUJIFILM`，转小写，空格转 `-`，保留连字符与后缀。
- `variant`：
  - `body`：机身（固定镜头机也用 `body`，卡口字段为空/N/A）；
  - `kit-{lens-slug}`：厂商/官方旗舰店定义的套机；
  - `bundle-{lens-slug}`：非官方套机的“单机身+镜头”捆绑，单独一类。
- 颜色、套餐、赠品**不进 id**，做 `color` / `package` 属性。

示例：

| 商品 | id |
|---|---|
| X-T5 机身 | `fujifilm/x-t5/body` |
| X-T5 + XF16-50 套机 | `fujifilm/x-t5/kit-xf16-50-f2.8-4.8` |
| X-T5 + XF16-80 套机 | `fujifilm/x-t5/kit-xf16-80-f4` |
| X100VI | `fujifilm/x100vi/body` |
| X half | `fujifilm/x-half/body` |
| X-E5 + XF23 F2.8 套机 | `fujifilm/x-e5/kit-xf23-f2.8` |
| X-T50 单机身 + XF35 F1.4（非套机） | `fujifilm/x-t50/bundle-xf35-f1.4` |

### 3.2 归一化与别名

- 只做大小写、空白、全角/半角、`FUJIFILM` 前缀的归一；**不删**末尾的 `V`、`VI`、`II`、`III`、`S`。
- 标题常见写法 `XT5`、`X-T5`、`X T5` 归一到同一 alias；但 alias 表必须**精确命中**，不做“去掉后缀后前缀匹配”。
- 镜头别名单独维护：`1680` → `XF16-80mmF4 R OIS WR`，`1650` → `XF16-50mmF2.8-4.8 R LM WR`，`23F2` → `XF23mmF2 R WR`，`35F2` → `XF35mmF2 R WR`。缩写只作输入别名，**入库用官方镜头名**。
- `X half` 与 `X-HF1` 是同一商品：官方规格写 `FUJIFILM X half (FUJIFILM X-HF1)`，id 统一用 `x-half`，`x-hf1` 作 alias。

### 3.3 同名不同代怎么区分

| 易混 | 区分办法 | 反例（禁止） |
|---|---|---|
| X100V vs X100VI | 型号字符串本身不同；X100V 页面 `Discontinued`，X100VI 当前线；官方 URL 不同 | 把 `X100VI` 归一成 `X100V`，或按前缀匹配 |
| X-T30 II vs X-T30 III | 保留 `II/III` 后缀；发布日/URL 辅助 | 去掉罗马数字后合并 |
| X-E4 vs X-E5 | 独立 slug；X-E4 只在“在列旧款”，X-E5 在当前线 | 用 `X-E` 前缀聚合 |
| X-H2 vs X-H2S | `S` 是不同机型，不是同款配置 | 把 `H2S` 当 `H2` 的套机/版本 |
| X-S10 vs X-S20 | 代际数字不同 | 用 `X-S` 前缀聚合 |
| X100V vs X100F/T/S | 后缀字母是代际，不是颜色 | 去掉末尾字母做模糊匹配 |

**判定顺序**：官方型号精确匹配 → alias 表精确匹配 → 官方 URL slug 精确匹配 → 仍不中则拒绝入库，人工确认。不要用相似度兜底；这条线同名不同代太多，错配比缺数据更贵。

## 五、与小米 / Apple / 大疆三条线对比

> 小米、Apple 的结论来自本仓库既有侦察（`docs/苹果官网采集侦察-2026-10-16.md`、`src/goodsdex/sources/mi_cn.py`）；大疆为经验判断，**本轮未复测**，只用于量级对比。

| 维度 | 小米 | Apple | 大疆（未复测） | 富士 |
|---|---|---|---|---|
| 公开名录 | 强（商城分类/搜索接口） | 强（compare 页） | 强（官方商城） | 强（X 系列页 + 规格页导航） |
| 规格结构化 | 强（接口字段） | 强（compare 表，20 维） | 强（产品页参数） | 强（HTML 表/div，37–48 条） |
| 官方人民币价 | **强**（接口直接给） | **弱**（价格在商店流程；curl 503，需浏览器） | **强**（官方商城直营价，经验） | **无**（官网不标；天猫 302；京东登录门） |
| 主图 | 强 | 强 | 强 | 强（CDN 匿名 200） |
| 稳定 id | `product_id` | 型号 | 型号 | 型号 + 机身/套机后缀（需自建） |
| 反爬 | 中 | 高（503/商店状态） | 中 | **中高**（Cloudflare + 天猫/京东登录与风控） |
| 套机/版本 | 有 SKU | 容量/颜色 | 有套装 | 有，但只在京东版本矩阵里，官网不写 |

**富士缺什么**

1. **缺价格**：这是和小米/大疆最大的差距；和 Apple 比也更差——Apple 价格至少在商店流程里公开（浏览器可读），富士是登录门。
2. **缺官方商品 id/API**：小米有 `product_id` 和商品接口；富士只有型号 slug，套机后缀要自己建。
3. **缺统一规格模板**：Apple 一张 compare 表覆盖多机型；富士一代机型一套 HTML，旧表/新 div 两种结构。
4. **缺套机的官方规格**：官网只写机身，套机含什么镜头只能从京东版本名反推，且有 `1680`/`1650` 这种缩写。

**风险更高还是更低**

- 比小米/大疆**更高**：多一层天猫/京东登录与风控，且价格字段根本拿不到；京东搜索一次就进 `risk_handler`。
- 比 Apple **略低**：富士规格页 raw HTTP 可读，不需要浏览器；Apple 商店 503、需要浏览器驱动。但富士价格更差，旧款页面还会 301/403。
- 结论：**富士是“Apple 式的规格页 + 京东/天猫式的价格门”**，不是小米那种“接口全给”的线。

## 六、实现判断

### 结论：有条件值得接

**值得接的部分**：机型档案（名称/型号/主图/规格/官方 URL）、机身与套机的分 id、旧款状态。这些能免登录、低频、稳定拿到，规模只有 24–26 条，人工校验成本可控。

**前提条件（缺一不可）**：

1. **产品上允许价格为空**。价格字段写 `null` + `price_source=null` + `price_note=暂无官方人民币价`，不能拿 USD 或第三方价填充。
2. **只做机型档案/展示，不做比价、促销、历史价格曲线**。没有官方 CNY 价，做价格类功能会误导。
3. **解析器同时支持 TablePress 表和 `div + h6`**，标签中英双语映射；对 11 个当前线型号做一次人工抽检（至少 5 台，按本报告第四节的字段数验收）。
4. **套机别名表人工维护**：`1680/1650/23F2/35F2/XC35/15-45` 等缩写映射到官方镜头名；`kit-` 与 `bundle-` 分开；颜色不进 id。
5. **采集纪律**：周/月频次、串行、缓存、只碰产品/规格页；不碰 `/cn/search/`、不登录天猫/京东、不重试 `risk_handler`、遇 403/429 立即停。
6. **图片下载后自存**，不长期热链；保留来源与版权字段。

**如果业务硬性要求“官方人民币价”才能上线**：本轮**不建议接**。替代方案只有三条，且都不完美：

- 等富士官方商城/天猫/京东开放公开价格接口（目前没有）；
- 走京东联盟等有授权的商品 API（需权限，且是平台价，不是官网价）；
- 人工维护“发布时建议零售价”并标注日期/来源（只适合少量旗舰机，不适合全量）。

**如果只是补“富士相机”这个品类的内容/参数页**：值得接，按上面的“无价机型档案”做，先接 11 台当前线 + 13 种套机，旧款 X-E4/X100V 以 `status=discontinued/legacy` 保留，不删。
