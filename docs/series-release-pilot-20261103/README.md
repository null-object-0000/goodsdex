这些配件本轮没有任何单品日期或系列日期。主机发布新闻不能证明耗材、替换件的首次上市时间，也不存在可向这些记录继承的整机发布批次。因此这套继承口径永久排除配件，保持日期空；不会把主机年月或抓取时间编成配件日期。“不适用继承”与“尚缺整机证据”分别记录，不许承诺靠此方案补到100%。

实现：独立输入 `data/official/series-releases.json`，`scope=pilot`，只有上述17个审核成员。每个成员绑定ID及名称/型号/参数哈希，行情价格和抓取时间不参与身份；身份变化、重复批次/成员、跨市场、配件或服务成员直接失败。新商品不会靠模糊匹配自动加入。字段为 `series_release={date,granularity,source,evidence,market,event,level:"series",batch_id,...}`。单品 `release` 不被赋值；单品验证器拒收 `level=series` 或 `source=series`。正常finalize在单品日期处理后重放批次，索引和详情均保留独立字段。

内部选择顺序：有效单品官方（含既有隐藏官方参考）>单品第三方>系列官方>系列第三方>LLM。相同ID被多个批次申领直接拒绝，需先人工解决，不能凭覆盖率选日期。已有禁用断言不参与内部排序，所有原始字段继续保留。系列断言可同时保存在有单品日期的记录上，但不会覆盖单品日期或用于替代更高优先级判断。
