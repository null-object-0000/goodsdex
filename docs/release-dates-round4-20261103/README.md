## 访问失败证据

- 大疆7条旧归档最初触发本地SOCKS传输错误；使用支持现有SOCKS配置的curl补核后，实际均为**404**。保留原本地错误与新的HTTP响应，不将这些7条计为成功正文，也不把404当成“目标日期不存在”。[补核明细](local-transport-recheck.json)。
- 小米 `https://ir.mi.com/zh-hans/news-events/news-releases` 及 `?page=0/1`：**403 Access Denied**，正文含Akamai Reference及errors.edgesuite.net，原始响应、hash和时间均保留。不能据此说官方无日期。
- 惠普 `https://www.hp.com/cn-zh/newsroom.html` 与 `/newsroom/press-releases.html`：**404**；中国about页链接实际是 `/us-en/newsroom.html`。未将美国系列发布当国行218个SKU的上市日。
- 富士误猜根 `/sitemap.xml`：404；读取robots找到 `/cn/sitemap.xml` 后成功。`/news?page=`是空列表壳，实际可用的是 `/news/list/3/all/all/all/pN`，保留两者区别。
- 比亚迪汽车站根sitemap：200但0字节；集团站robots与根sitemap：404。实际新闻列表API成功，不把空sitemap当成无新闻。
- 惠普中文URL最初遇到本地ASCII编码异常，修正URL编码后12篇正文和5个分类页全部200；这是本地请求构造错误，**不是服务器拒绝证据**。

扫描脚本按host共享文件锁，网络请求开始间隔至少2.15秒，响应缓存和正文hash保留；不登录、不绕验证码、不请求京东。早轮同日证据直接复用，避免重复抓取。原始响应按URL留档并记录完整内容hash；精确候选人工allowlist与发现队列分离。

## 公开源覆盖率上限判断

**按当前可访问公开源和精确型号口径，这个字段的实用上限大约20%，乐观区间约20%–25%；本轮17.49%已进入这条路线的边际增量区间，不再承诺下一轮翻新闻还能显著上涨。** 这是工程估计，不是已证明的全网数学上界。

依据：本轮取得大疆464篇、富士268篇和比亚迪两站196篇正文；大疆另7条已逐一尝试并保留404证据，新增只落到大疆21个ID，富士/比亚迪0；Apple新增125，但剩余181大多是旧型号或还缺精确配置证据。全库剩余3274行中，小米2136、大疆676、惠普218合计3030行，占92.55%，主体是未取得公告的家电/配置/后续套装/配件，不能从主机或系列替代。即使极乐观地把Apple640、富士63、比亚迪14三品牌全都补为真源，其他品牌保持本轮成果，也仅 **938/3968=23.64%**，仍不接近60%。小米403留下未决空间，所以不能把抓取受阻当作这个估计的“无数据证明”。

可展示的本轮147条全部是official/fact，UI应按release.label分别显示发布时间/发售时间；没有海外稿进入新增展示。既有40条LLM和31条计划发售保留原来源、label与usage，未改为官方已开售。这里验证API数据契约，不声称修改另一个客户端仓库或做过客户端截图验收。
