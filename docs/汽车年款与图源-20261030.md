# 汽车按「系列 + 年款」组织：官方口径与整车图源核查（2026-10-30）

> 范围：只核查公开页面/接口；不登录、不绕验证码；不写库、不改脚本、不推分支。
> 实取时间：2026-10-30 08:46–09:06 CST。
> 结论只覆盖本轮实际取到的页面/接口；拿不到的地方明确写“拿不到”，不用行业常识补。

## 0. 结论先行

1. **比亚迪官网没有“年款”字段或年份切换器。** 年款只以两种形式出现：① 少数商品名里带“2026款/2025款/2027款”；② 第三方参数站把某个配置标成“2022款”。参数表本身只有“车型”（配置）分组，没有“年款”行。
2. **小米汽车官网也没有“年款”字段。** 当前官方叫“新一代 SU7”，不是“2026款”；接口里 `pdfFileName` 原文就是“新一代SU7参数配置表”。官方参数对比页只有 3 个车系、10 个版本，没有 `year`/`modelYear`/`年款` 字段。
3. **汉 DM-i 2022 款的官方整车图拿不到。** 旧官方车型页 `https://www.byd.com/cn/dynasty-home/models/han/han-dm-i` 实取 404；当前 CMS 的汉 DM 车系下只剩官方名为“汉DM-i智驾版”的当前商品（goodsId=130，官方名未写年款）；官方新闻接口的 170 条记录最早到 2023-01-03，没有 2022 年条目。不能用当前款的图冒充 2022 款。
4. **DM-i 应作为“动力规格/动力分支”，不应塞进配置（trim）里。** 官方把汉 DM-i 和汉 EV 做成两个独立商品（goodsId=130 / 131）、两套参数表；DM-i 参数表有发动机型号/排量（动力性能）和油箱容积（尺寸参数），EV 则是电机型式/驱动型式/CLTC。它和“121KM/242KM、尊贵型/旗舰型”不是同一层。
5. **“系列 + 年款做商品、配置做规格”方向可行，但不能全靠官方字段自动生成。** 官方只稳定提供“车系/商品 + 配置 + 价格 + 图片”，不提供年款。年款必须做成带来源和置信度的受控映射；没有证据时 `model_year=null`，不要写 “unknown” 当值。

- **按官方口径：没有“SU7 2026款”这个名称或字段。** 官方当前只叫“新一代 SU7”，配置表 PDF 名也是“新一代SU7参数配置表”。

#### 1.2.4 小米车系/年款的表达方式

| 车系 | 官方版本名 | 年款表达 |
|---|---|---|
| SU7 | SU7 / SU7 Pro / SU7 Max | 无；官方叫“新一代 SU7” |
| YU7 | YU7 标准版 / 长续航版 / Pro / Max / GT | 无 |
| SU7 Ultra | SU7 Ultra / SU7 Ultra纽北限量版（2025版） | 仅限量版 trim 名里带“2025版” |

该接口只覆盖当前列出的 3 个车系/10 个版本；不能据此断言历史停售版本不存在，也不能据此补出“2024/2025 款”。

#### 1.3.4 未验证：工信部公告 / 免税目录

本轮**没有取得**能把“2022款 121KM 尊贵型”直接映射到某个公告型号/批次页的可复核公开页面，所以不把工信部公告、免税目录写成已验证来源，也不据它们填任何字段。

可行性判断（不是已证实结论）：

- 公告/目录是强官方证据，适合核对“某型号在某批次是否存在、电池/续航等参数是什么”；
- 但它们按车辆型号/批次组织，不是按“2022款 121KM 尊贵型”这种商品名组织；要用必须先建立“型号 ↔ 配置”的映射，成本高；
- 在本轮缺页的情况下，**不能拿公告常识替代页面证据**。后续如果要做，应把公告批次页、型号、配置映射逐条留档，再标 `official`。

#### 1.3.5 建议的证据等级

| 等级 | 来源 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| A | 比亚迪/小米官方商品接口、参数表 | 当前商品名、配置、价格、图片 | 历史年款、已下架商品 |
| B | 厂商发布信息/上市报道（官网或媒体转载） | 某日发布了某车系 | 商品年款字段、逐配置 |
| C | 第三方参数站（太平洋/汽车之家） | 明确的“2022款 + 配置”页面 | 官方命名、官方图片授权 |
| D | 社区/二手/自媒体 | 线索 | 不作为字段依据 |

本轮汉 2022 款的年款判断只能落在 **C**；2022-04-10 的上市报道只能算 **B-**，用它交叉支持发布日期，不能把年款标成 A/B。

## 2. 整车图源

### 2.1 比亚迪：当前款可以按配置定位，但不能按年款定位

`GET https://cms-api.byd.com/car/byd/cn/getGoodsAttrListForCompareByGoodsId?goodsId=130`（200，119,669 字节）的每个配置对象里都有：

```json
  "name": "125KM尊贵型",
  "seriesImg": "https://cache.bydauto.com.cn/dilink_user_upload/manage/202510/11/194709ZHqqYTdC.jpg",
  "seriesImgPc": {"_path": "/material/domestic-official/order-optional/dynasty/han/han-dm-i-zhijia/02-waiguan/125km-zungui/02-gray.png"}
}
```

同样 `goodsId=131` 的 635KM 旗舰型：

```json
{
  "name": "635KM旗舰型",
  "seriesImg": "https://cache.bydauto.com.cn/dilink_user_upload/manage/202510/31/1820380yiMj6A6.jpg",
  "seriesImgPc": {"_path": "/material/domestic-official/order-optional/dynasty/han/han-ev-zhijia/20251010new/waiguan/635KMzunrong-jin.png"}

```

要点：

- **能按“系列 + 配置”定位**：路径里带 `han-dm-i-zhijia/125km-zungui`、`han-ev-zhijia/635KMzunrong-jin`，一个配置一个图。
- **不能按“年款”定位**：路径和字段里没有年份；`han-dm-i-zhijia` 是商品/代际 slug，不是年款。当前 goodsId 本身就不携带年款。
- **有两套图**：`seriesImg` 是带价格/权益文案的商品卡（1920×1077）；`seriesImgPc` 是透明底外观渲染图（1125×720 或类似），更适合做主图。
- **图种**：本轮样本都是车身外观图/官方宣传图，没有取到或使用内饰图；`seriesImg` 属于宣传物料，`seriesImgPc` 属于配置外观渲染。

对于 2022 款，没有对应的 goodsId，也没有 2022 的 `seriesImg`/`seriesImgPc`，所以这套“按配置定位”的能力**只覆盖当前在售商品**，不能外推到 2022。

- **不能按配置定位**：3 个 SU7 版本共用一张，5 个 YU7 版本共用一张；
- **不能按年款定位**：官方没有年款字段，图片 URL 里也没有年款，只有素材日期目录（如 `su7_20260319`）。

### 2.3 汉 DM-i 2022 款：官方整车图拿不到

**结论：拿不到官方整车图。** 不是“没找到”，而是当前官方公开渠道已经没有这张图的可定位入口：

1. 旧车型页 `https://www.byd.com/cn/dynasty-home/models/han/han-dm-i` 实取 404；

## 4. 判断与数据结构

### 4.1 DM-i 算不算一种“规格”？

**判断：算“动力规格/动力分支”，不算配置规格（trim）。**

依据不是行业常识，而是官方商品结构：

1. **独立商品**：汉 DM-i 是 `goodsId=130`，汉 EV 是 `goodsId=131`；两个商品、两个详情页路径：

```json
{"id":"130","name":"汉DM-i智驾版","price":"168,800 - 225,800","detailPage":{"_path":"/cn/dynasty-home/models/han/han-dm-i-zhijia"}}
{"id":"131","name":"汉EV智驾版","price":"179,800 - 215,800","detailPage":{"_path":"/cn/dynasty-home/models/han/han-ev-zhijia"}}
```

2. **两套参数表，动力段字段不同**：DM-i 的“动力性能”组含 `发动机型号 / 发动机型式 / 排量(L)`，“尺寸参数”组含 `油箱容积(L)`；EV 的“动力性能”组含 `电机型式 / 前电机最大功率 / 前电机最大扭矩 / 驱动型式 / CLTC综合工况纯电续驶里程`，没有发动机/油箱字段。

3. **配置列是另一层**：DM-i 内部有 9 个 `车型`（125KM 舒适/精英/尊贵/尊荣/激光雷达旗舰 + 245KM 舒适/尊贵/尊荣/激光雷达旗舰）；EV 内部有 5 个 `车型`（506 尊贵、605 尊荣、635 旗舰、635 激光雷达旗舰、705 激光雷达旗舰）。DM-i vs EV 是这些配置列之上的分支。

**所以：**

- 数据上应放 `powertrain`（`DM-i` / `EV` / `DM-p`），与 `model_year` 同级；
- 不要放 `trims[].name`，也不要把“DM-i”塞进参数 key；
- 如果产品 UI 只有“规格”一栏，可以把“动力形式”作为规格组的第一个字段展示，但底层必须是独立字段；它不能和“121KM/尊贵型”混成同一层选项。

### 4.2 “系列 + 年款做商品、配置做规格”是否可行？

**方向可行，但不能全靠官方字段自动生成。** 官方字段支撑情况：

| 目标字段 | 比亚迪官方 | 小米官方 | 结论 |
|---|---|---|---|
| series（车系） | 商品名里有，但混入动力/代际/版本（“汉DM-i智驾版”“2026款夏”） | `pdfFileName` / `carItemId` 干净（SU7/YU7/SU7 Ultra） | 需要人工规范化 |
| model_year（年款） | **无字段**；少数商品名带年份 | **无字段**；只有“新一代”“2025版” | 必须做受控映射，不能自动 |
| powertrain（动力） | 体现在商品名/独立 goodsId；无独立字段 | 全是 BEV；无字段 | 需从商品/参数表抽取 |
| trim（配置） | `车型` 值，稳定 | `pcCarVersionName`，稳定 | 可直接用 |
| price | `price` / 参数表“建议零售价” | `pcCarVersionPrice` | 可直接用，但注意“限时价”不是 MSRP |
| image | 当前款按 trim 有 `seriesImgPc` | 公开页按 series 共用；配置器有按 ssu 的资源 | 图片粒度不一致 |

**可行结构（建议）：**

> 示例中的 215,800 元来自既有已审阅证据 `docs/汉DMi2022-20261029.md`（2022-04-10 厂商上市价图），不是本轮新取；`121` 来自 pcauto 的“121km”配置名。

### 4.3 落地风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 年款误判 | “2027款元UP飞驰版”“2025款海豚”“第三代秦PLUS”“2025版”混在一起；商品名年份可能是未来年款/限量版年份/代际 | 人工审核 + `model_year_source` + 置信度；不要正则批量拆名 |
| 历史官方数据缺失 | 2022 汉页面 404，CMS 只返回当前商品；历史款无官方图/参数 | 历史款用第三方 C 级证据；图片 `null`；不要借新款图 |
| ID 迁移断链 | 现有 ID 把 `unknown` 写进主键；改成 `series:year:powertrain` 会换 ID | 新 ID + `legacy_ids` 映射；旧链接 301/别名；不要原地改 |
| 图片错配 | 当前“汉DM-i智驾版”图被当 2022 款；YU7 GT 图被当标准版；SU7 图被当 Max 专属 | `image_scope=series/trim`、`image_source_type`、`review_status`；共享图显式标注 |
| 价格/参数跨年覆盖 | 同名车系不同年款价格/续航不同，合并会互相覆盖 | 按 `year + powertrain + trim` 快照；只追加，不覆盖 |
| 第三方年款漂移 | 太平洋/汽车之家可能改标题、合并配置 | 保存页面快照/SHA256/抓取时间；年款来源可追溯 |
| 图片版权 | 官网图可公开访问 ≠ 可商用 | 入库前确认授权；发布报道转载图单独标注来源/非官方 |
