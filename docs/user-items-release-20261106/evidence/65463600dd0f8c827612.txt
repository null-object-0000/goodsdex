小米618终极攻略：Redmi新品现货，生态链数十款新品齐开售

来源：

作者：

责编：

6月17日消息 随着6月18日的临近，一年一度的电商618大促即将到达高潮。小米也参加了此次618大促，这也是小米品牌和Redmi品牌分开后的首次618大促，而在此之前无论是小米集团创始人雷军还是Redmi品牌总经理卢伟冰，都在各种公开场合强调Redmi品牌将主打电商，所以618大促无疑将成为Redmi品牌的主战场。
6月18日当天，小米将有数十款人气新品齐开售，商务旗舰小米MIX 3闪降1000元，Redmi家族“小金刚”和“大魔王”分别主打闪降200元和买赠活动，电视空调洗衣机组合的大家电产品齐开售，小米手环4等上百款智能家居享特惠。与此同时，小米商城/小米之家/小米有品/京东/天猫/苏宁/唯品会等平台，也为大家准备了各具特色的好礼，官方称总让利超过5个亿。
Redmi品牌的主战场，人气新机现货购买福利多
在6月1日到6月16日期间，Redmi手机多次夺魁，6月1日当天K20Pro夺得京东手机销量单品排名第一。
在6月16日-6月18日，“小金刚”和“大魔王”纷纷都参与活动，购买即享超值福利。小金刚Redmi Note 7 6GB+64GB立省200元，到手价仅需1199元；Redmi Note 7 Pro在6月18日当天闪降200元，到手价仅需1399元；Redmi K20 Pro售价2499元起，活动期间可享3/6期分期免息政策；Redmi K20 1999元起，6GB+64GB/6GB+128GB版本买即送69元小米耳机。
6月16日-6月18日，滑盖全面屏手机小米MIX 3立省1000元，到手价仅2299元起；全息幻彩玻璃机身小米9 6GB+128GB立省200元，到手价仅需2799元；此外小米9另外两个版本也有好礼相赠，8GB+128GB版本买就送价值149元无线充电宝、8GB+256GB版本买就送价值169元无线车充；小屏旗舰小米9 SE 6GB+64GB/6GB+128GB买就送299元小米AI音箱。2400万自拍旗舰小米8青春版6GB+64GB立省400元，到手价1099元。
小米电视爆品低至699元
小米的大家电在618期间的最终成绩如何现在还不得而知，据相关人士透露小米电视此次优惠力度堪称罕见“动不动就省1000元2000元！”，6月18日当天小米电视4S 75英寸立省2100元，到手价仅需5899元；小米全面屏电视E65A立省1000元，到手价仅需2999元；小米电视4X 65英寸立省1100元，到手价仅需2599元；小米全面屏电视E55A立省1000元，到手价仅需1999元；小米电视4X 55英寸立省600元，到手价仅需1799元；小米电视4A 50英寸立省700元，到手价仅需1399元；小米电视4A 32英寸立省200元，到手价仅需699元。
6月18日，米家互联网空调C1（一级能效）立省600元，到手价仅需2199元；米家互联网空调C1立省400元，到手价仅需1999元；米家互联网空调（一级能效）立省700元，到手价仅需1999元；米家互联网立式空调C1于6月18日0点开售，立省500元，到手价仅需2999元；米家互联网空调立省400元，到手价仅需1799元；米家空调立省300元，到手价仅需1499元。
除了电视和空调以外，6月16日-6月18日，米家互联网洗烘一体机10kg立省400元，到手价仅需1799元；Redmi全自动波轮洗衣机1A 8kg立省100元，到手价仅需799元，新品米家滚筒洗烘一体机1A 8kg立省300元，到手价仅需1699元。
小米AIoT上百款智能好物享好价
目前来看，小米品牌在京东618智能家居排行榜上稳居第一。6月11日刚刚发布十数款的AIoT新品扎堆首销：6月18日10点，小米手环4 NFC版229元首卖；小米巨能写中性笔10支装，仅售9.99元；RedmiBook 14仅3799元起，小米小爱音箱Play 169元，两款爆品于6月18日0点开售；169元的小米手环4标准版、以及499元起的小米小爱老师，都将于6月18日10点开售。小米笔记本Pro 15.6" 2019款最高立省800元，到手价4999元起；小米净水器600G立省500元，到手价1999元；小米米家智能门锁黑色标准版立省100元，到手价不高于1199元；米家酷玩产品线的又一新品米家九号平衡轮，双轮独立自平衡设计，也将于6月18日0点首卖，售价999元。
同时，米家电磁炉锋味套装众筹中，众筹价仅499元，另有两款厨房小家电米家电烤箱和米家电饭煲4L，也首发开卖，售价均为299元。
此外，小米与Line Friends的又一款合作产品——小米旅行箱20英寸布朗熊限量版也已经现货开售，旅行箱整体为棕色外观，印着可爱的布朗熊形象，颜值颇高，适合作为登机箱使用，售399元。
全时段、全渠道超多福利
在6月18日当天，无论是在小米商城，还是京东、天猫、苏宁等电商平台的小米官方旗舰店，都有多种趣味玩法和超多福利。
在小米商城，从8点-19点每个整点抢人气爆款1折券；每天10点/14点/20点，超值好物一口价秒杀；还有3000万红包雨，Redmi K20 Pro、618元神券、超多实物好礼等你赢！在京东，只需关注小米京东自营旗舰店，即可获得抽取新品手机、洗衣机等大奖的资格。此外，还有以旧换新最高赢300元京东E卡补贴等机会；在天猫，关注/收藏/加购即可参与活动拼手气抽Redmi K20 Pro，每天早10点，1000元无门槛优惠券准时开抢，Redmi 7手机0元试用，参与盖楼、投票等互动赢好礼；在苏宁，爆款小米手机低至0.01元秒杀，智能3C爆品低至5折起……
