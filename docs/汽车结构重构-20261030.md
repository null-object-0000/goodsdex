# 汽车结构重构（2026-10-30）

按「系列 / 年款 / 动力 / 配置」组织。仅迁移比亚迪与小米汽车；“小米”数码家电、大疆、Apple、富士、惠普逐字段保留。未修改首页、我的页、隐私或账号源码。

## 新 schema 与身份

一条 `car-product-v2` 商品含 `id=product_id`、`brand`、`series`、`model_year`、`model_year_source`、`model_year_confidence`、`model_year_source_url`、`powertrain`、`edition`、`generation`、`official_name`、`name/display_name`、`trims[]`、`legacy_ids[]`、`image`、`image_status`、`image_scope`。

```json
{
  "schema": "car-product-v2",
  "id": "CN:byd:car:han:2022:dmi",
  "product_id": "CN:byd:car:han:2022:dmi",
  "series": "汉",
  "name": "比亚迪 汉 2022款 DM-i",
  "model_year": 2022,
  "model_year_source": "pcauto",
  "model_year_confidence": "third_party",
  "model_year_source_url": "https://price.pcauto.com.cn/m112979/config.html",
  "powertrain": "DM-i",
  "image": null,
  "image_status": "official_unavailable",
  "image_scope": null,
  "trims": [{
    "id": "CN:byd:car:han-dmi:2022:121km-112979",
    "name": "121KM 尊贵型",
    "price": 215800,
    "price_kind": "msrp_historical",
    "range_km": 121,
    "range_std": "NEDC",
    "image": null,
    "image_status": "official_unavailable"
  }]
}
```

示例省略了其余4个配置、params和证据。每个 trim 的 `source_record` 原样保存旧记录，保留逐参数来源、历史价格依据、抓取时间等；`params` 按配置保存，绝不跨配置合并。旧配置 ID 继续作为 trim ID（其中历史的 `:unknown:` 仅是旧主键中的字符，不是年款字段）。新商品 ID 不含 unknown；当前商品用官方 goods/item ID 固定代际边界及 `current`，历史汉用 `han:2022:dmi`。没有年款的不同官方商品不凭上市时间或相似名称强并。

商品 `price` 是非空配置价格的最小值，`price_kind=from`，不能当作所有配置价格。配置独立保留 `msrp` / `msrp_historical` / `none`，领航型历史价格仍为 null，不用0或其他配置价格填补。121/242KM 保持 NEDC，不改写成 CLTC。

原始 `data/official/car-catalog.json`（43条）、历史已审阅档案（5条）继续作为不可覆盖的采集证据。`data/official/car-products.json` 是对应的离线迁移产物。`scripts/migrate_car_structure.py --public <目录>` 可单独迁移；发布 finalizer 自动执行相同迁移。重复执行幂等。每日车源刷新先恢复原始配置快照、执行原有白名单/证据校验，再重新归组；小时刷新继续整对象保护汽车。最终发布的“旧 ID 不丢失”门禁把 `legacy_ids` 算为可追溯身份，不取消守卫。

## 年款与动力规则

|情况|model_year|source|confidence|
|---|---|---|---|
|官方商品名明确标年款（本批为2026款夏）|2026|official_name|official|
|太平洋对应历史参配页明确标2022款|2022|pcauto|third_party|
|官方没有年款| null |official_absent| null |

不使用 CMS createdAt、素材目录日期、上市年份或“新一代”推断年款；`model_year` 不允许字符串 unknown。小米 SU7 官方名为“新一代 SU7”，model_year=null；YU7、SU7 Ultra 同样为 null。纽北限量版的“（2025版）”留在配置名中，不能变成年款。

`powertrain` 独立为 DM-i / EV（可扩展 DM-p / 增程），不塞进 trims.name。规范化映射固定在 `src/goodsdex/car_structure.py`；官方商品 goodsId=130 和131分别映射汉DM-i与EV，代际/智驾版另有字段，不污染 series。

## 图片状态与缺口

|image_status|含义|客户端|
|---|---|---|
|available|已审阅的对应官方图可用|显示图片；车系共享图明确标“车系参考图”|
|official_unavailable|现有证据确认当前公开官方渠道无法定位对应整车图|image=null，显示“官方图待补”|
|missing|缺图，尚无足够证据下 official_unavailable 结论|空图与分类占位，不使用品牌 logo|

`image_scope=series` 表示车系级；`trim` 表示配置级；无图为 null。小米3个商品的全部10个配置共用车系图，均标 series，不能称为 SU7 Max 或 YU7 标准版专属图。

## API 与录入

汽车搜索默认返回商品；`group_products=1` 沿用商品展示合同。`q=汉 121` 会搜索嵌套 trims，命中汉2022商品，并保留该商品全部5个配置供选择。`series=汉`、`powertrain=DM-i`、`model_year=2022/null` 可筛选；游标签名包含这些条件，禁止跨筛选复用。facets.series / facets.powertrain 按商品计数，与 trim 个数分开。

`GET /api/goods/<新商品ID>` 返回完整商品及 trims；旧配置ID仍能解析，返回带 `product_id`、`trim_id` 的单配置投影。`/api/goods?product_ids=...` 为现有选择器返回完整配置投影及 presentations，不把投影当作多件物品。分片索引只含轻量 trim 字段，详情恢复完整参数、证据快照；新增测试专门保证 hydration 不被轻量 trims 覆盖。

录入依次选年款→动力→配置；不会预选唯一年款或动力来绕过用户核对。空年款选项显示“不记得年款”，选择值只用于UI，底层 model_year 仍为 null。确认后单件物品保存一个 product_id+trim_id；历史参考价不写入购入价，导出导入后身份和实付价不变。
