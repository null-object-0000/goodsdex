## 每日 workflow 与小时保护

- 名称：`refresh-cars`；文件：`.github/workflows/refresh-cars.yml`。
- cron：`17 4 * * *`（UTC；北京时间每天 12:17）。
- 每日路径：`scripts/car_catalog.py --approved` → `scripts/publish_cars.py` → 只提交 goods.json/meta.json 到 data → 复用 `scripts/mirror_public_to_oss.py`。
- 本轮手动验证传 `verified_only=true`，由 car_catalog 复制本地核实输入，**没有网络采集**。
- 缺任一 OSS 密钥立即失败。镜像后通过 OSS SDK GET 读回两个文件、逐个比 SHA256，并输出完整 meta.json。
- 与小时级 workflow 共用 `goodsdex-data-publication` 串行锁；小时任务最终提交前显式比对车总数、product_type=car 数和完整对象。
- 针对性验证：`uv run --with pytest python -m pytest -q tests/test_car_catalog.py tests/test_publish_cars.py`，**17 passed**。未运行全量小程序测试。
