# 调研：富士（仅相机品类）能不能接进商品库

## 一句话目标

判断**富士相机**（机身与套机，不含配件耗材）能否像小米/Apple 那样接进我们的商品库：**免登录**拿到 **名称 / 价格 / 主图 / 参数**，并说清拿不到的字段与风险。

## 范围（严格）

- **只做相机品类**：可换镜头机身（X-H / X-T / X-S / X-Pro / X-E 系列）、固定镜头机（X100 / XF 系列）、以及它们的**官方套机**；
- **不做**：镜头单卖、instax 一次成像、配件、耗材、打印设备、医疗/工业产品；
- 一个商品一行：**机身与套机分开算**（套机在参数里写清含什么镜头）。

## 要回答的问题（按重要性）

1. **有没有免登录可用的公开页面/接口**：富士中国官网（fujifilm.com.cn）与官方商城的**商品页/规格页**，能不能直接读到相机型号、价格、主图、参数？逐项给出「能/不能 + 证据 URL + HTTP 状态」。
2. **价格到底有没有官方标价**：很多影像厂商官网只列参数不标价。请明确：
   - 官网是否标人民币价？若有，是"建议零售价"还是"当前售价"？
   - 若官网不标价，**官方商城/官方旗舰店**是否公开标价、是否免登录可读？
   - **不许拿第三方比价站的价格冒充官方价**；如果只能拿到第三方价，必须单列并标明来源与风险。
3. **身份标识**：富士没有 CP 料号，那用什么做稳定 id？候选：官方型号（如 `X-T5`）+ 机身/套机后缀；请给出可复跑的规则，并说明**同名不同代**（如 X100V vs X100VI）怎么区分。
4. **参数结构化程度**：规格页是文字表格还是图片？能否稳定解析出「传感器画幅、像素、卡口、连拍、视频规格、重量、电池型号」这类字段？抽样 5 台机身给出实际拿到的字段数。
5. **规模**：在售机身 + 套机大约多少条？给出枚举方式（分类页/系列页/sitemap）与实测条数。
6. **风险**：条款与反爬（是否需要 UA/是否遇 403/412/风控脚本）、图片版权与热链、页面改版频率（有没有版本信息/构建号可判断）。

## 方法纪律（硬要求）

- **只碰公开页面/公开接口**：不登录、不绕验证码、不逆向 App、不伪造签名；
- 同一 host 间隔 **≥2.1 秒**、并发 1、**总请求 ≤200 次**，429/风控立即停并记录；
- 每条结论都要能追到 URL + HTTP 状态 + 关键片段摘录（**不长篇贴 HTML**）；
- 抽样要够：相机机身**至少 8 台**、套机**至少 4 条**、固定镜头机**至少 3 台**；
- 拿不到就写拿不到，**不许用"应该有"代替证据**。
