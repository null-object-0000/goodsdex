## 证据规则与不采信案例

- 官方优先使用小米业绩公告中的明确发布原句，保留PDF或官方PDF抽取文本、采集时间、SHA-256和哈希范围。未以当前参数页存在、型号年份、固件上线、接口抓取时间或文件名推导发布日期。
- 第三方按原始供稿机构标记；新浪转载快科技、泡泡网、北京商报、DoNews或C114时，publisher使用原机构，不把新浪站点当作新增独立来源。快科技原文出现登录墙时，失败原响应保留；实际采用同日公开Blog原文，未以受限页标题补日期。
- 非官方第二来源必须有完整采集证据，经型号/市场/事件/批次复核且原始供稿机构独立。≤14天可展示，15–45天保留内部、禁止展示，>45天置空并入人工复核；有一个一致结果不能盖掉已核实硬冲突。年精度第三方不能凭全年一致证明≤14天；本轮新第三方日期均为日精度。
- 系列支持year/month/day，展示字符串严格按取得的一级生成。没有运行任何LLM补日期、LLM交叉核验或模型调用。
- 6X首发三规格不包含后来4+32GB（8154）；红米6A只有6月13日已归档的初版8274纳入，7月归档容量未知的10000110留空；小米8青春/屏幕指纹版与5月8/SE/探索版分开，两个9月型号各有独立佐证。
- 小米电视4A只覆盖首发43/49/55/65英寸，32/40/50/58英寸、体育/影院版留空；电视4不把55/65日期继承给后来75英寸或影院版。
- 米家吸顶灯Pro的后续超薄版、一室/两室/三室套餐没有同批推出依据，未继承整机日期；旧款216L风冷冰箱与2026同容量新款23579分开；烟灶套装不直接继承净烟机P1日期。
- 米家冰箱Pro法式508L出现官方5月发布与第三方4月上架的不同事件线索，当前颜色/面板是否属于同一批仍需查证，21169/21192本轮不赋值；不拿2月冰羽白版本替代5月冰晶白/星缎银。560L法式自动制冰也不扩给十字或非制冰版本。
- 波轮Pro 10/12kg虽取得IT之家首发稿，找到的新浪为IT之家转载，ZOL促销稿参数又与首发不一致，未计作两个独立准确来源，24785/24786继续留空。没有为了扩大覆盖而放宽门槛。
