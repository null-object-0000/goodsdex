卢伟冰：未来随着新机陆续发布，大家一定会感觉 REDMI K100 Pro 系列越来越香

2026/8/11 23:05:09 来源：IT之家 作者：归泷 责编：归泷
评论：
感谢IT之家网友 Autumn_Dream、不一样的体验 的线索投递！

IT之家 8 月 11 日消息，小米 REDMI K100 Pro 系列手机今日正式发布，首批带来了 Pro Max 和 Pro 两款新机，后续还将发布标准版和游戏旗舰机。

小米 REDMI K100 Pro 系列手机售价如下：

REDMI K100 Pro

  • 12+256GB 版本 3999 元，首销 3699 元，国补价 3199 元；

  • 16+256GB 版本 4399 元，首销 4099 元，国补价 3599 元；

  • 12+512GB 版本 4599 元，首销 4299 元，国补价 3799 元；

  • 16+512GB 版本 4999 元，首销 4699 元，国补价 4199 元；

REDMI K100 Pro Max

  • 12+256GB 版本 4499 元，首销价 4199 元，国补价 3699 元；

  • 16+256GB 版本 4899 元，首销价 4599 元，国补价 4099 元；

  • 12+512GB 版本  5099 元，首销价 4799 元，国补价 4299 元；

  • 16+512GB 版本 5499 元，首销价 5199 元，国补价 4699 元；

  • 16+1TB 版本 5999 元，国补价 5499 元（限量两万台）

新机的价格也成为了大家讨论的热点。IT之家注意到，小米集团合伙人 / 总裁、手机部总裁、小米品牌总经理卢伟冰刚刚发文回应了新机定价，他表示：

未来随着新机陆续发布，大家一定会感觉 K100 Pro 系列越来越香

内存涨价的原因想必大家都听过很多了，AI 算力爆发虹吸产能 + 三大寡头控产 + 行业库存见底 + DDR4/DDR5 换代断档，四重因素叠加想不涨都难。事实上，各手机厂商的部分在售产品已调价，而接下来发布的新机也会不可避免地会迎来价格上的调整。
