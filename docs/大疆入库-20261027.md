## 身份与字段

- id 固定为 `CN:dji:sku:<products.variants[i].id>`，使用详情 JSON 的数字 id；不依赖名称、slug、URL 或 EAN。
- 分类列表中 17 个旧 id 与详情 id 不同，均以 **slug、官方原名、EAN 三项精确一致**核实列表引用对应关系；它们不产生第二条商品。最终 id 始终取详情 JSON，映射证据保存在 `data/dji/listing-id-aliases.json`。
- 不同套装、配色和遥控器版本各自一条。同 id 只保留一次；`family_id` 使用官方主变体数字 id，`variant_hint` 保留官方销售标题，`params` 保存可取得的销售选项、包装清单和套装组成。
- 商品层 `inTheBoxes` 通过官方 `productId` 与销售变体关联，不把其他套装包装清单混入。包含整机的 Bundle 继承实际整机部件的类型；配件套件仍为 accessory。
- `brand=大疆`，`price_kind=listing`，`catalog_identity=dji_mall_json`，`model` 与 `model_or_part_number` 均为 null；普通商品不写 `record_level`。
- 人民币证据取 JSON-LD `CNY`，或中国大陆本地化 JSON 的 `currency.code=CNY`，再核对变体人民币价标；使用数字 `price`，不用 0 表示缺价。
- 主图选官方 `cover.origin/original`，缺失才用 ultra，原 URL 原样保留，不构造图片地址。
- 技术参数只取商城结构化规格或官网 specs/支持页；保留系列、部件章节和原文适用范围，不从商品名提取技术参数，也不把部件型号提升为整套型号。

## 请求纪律与复跑

总计 **929 次**（包括最初 HEAD/首页 GET 两次、重定向、被中断的已发起尝试和十次最终抽检），上限 1,200。并发 1；账本实测同 host 请求开始时间最小间隔 **2.196193 秒**。429 / rate_limited 为 0；代码遇 429 写入原因、退避 60 秒后停止。

每个响应按 URL 哈希缓存；请求发起前先追加持续累计账本；跨次运行不能重置请求预算。互斥锁防止两个进程同时采集。每个枚举页面更新进度，解析/规格处理每 50 条写 checkpoint，日志位于 `data/dji/progress.log`。

同一份缓存完成全量离线复跑，新增请求为 0，catalog.json SHA-256 和文件字节均完全一致。解析测试另验证同样本两次 id 相同、变体不合并、服务/停售过滤、CNY 校验、真实配件分类、分页总数、缓存复用和只追加幂等性。

