## 4. 合并、保护与发布

使用 `scripts/publish_cars.py --historical-only`，该模式只追加与仓库已审阅历史证据包逐字段相同的记录；既有ID冲突立即拒绝，重复运行不产生重复行。价格必须为none或有official/official_news证据的msrp_historical；非官方图片拒绝发布；每个参数必须有来源。现有在售配置采集逻辑独立保留；每日汽车发布追加历史证据包，防止只靠一次手工补库。

本地以data分支ca6dd0b为基线：5541 → **5546**，新增5，更新0。全5541条旧记录原顺序逐字段一致，小米、Apple、大疆、富士、小米汽车逐条一致（`merge-audit.json`）。25项汽车采集及发布检查通过，包含重复运行、旧对象不变、ID冲突、未审阅数据拒绝、第三方价格与图片拒绝、缺参数出处拒绝。没有修改小程序或服务端。
