## 采集与发布规则

Apple Support 解析器版本升为 `apple-support-v2`。标题判据锚定开头，忽略大小写和标题外空白：`macOS <名称>`、`Mac OS X v?<数字版本>`、`iOS <数字版本>`、`iPadOS <数字版本>`，并覆盖 watchOS、tvOS、visionOS 数字版本。真实机型 `MacBook Pro (14-inch, 2021)` 保留。

目录产品卡先过滤；规格正文去除“技术规格 / Technical Specifications / Tech Specs”后再次过滤，以防目录错链或重定向。命中记录写进 `filtered_software`，不冒充网络/解析失败。旧缓存的同类软件记录不再进入增量机型输出；其他失败页原有记录及观察时间仍保留。

共用 supplements.merge 与最终发布门禁按精确 ID 移除六条，并将 ID 与理由写入 `merge-audit.json.allowed_deletions`。上一版 ID 丢失检查仅豁免这六条；任何其他 ID 丢失仍失败，不使用数量增长替代 ID 集合校验。最终门禁在写发布文件之前完成 ID 检查。

小米记录名称为空白、参数无有效值、没有图片、没有当前价/标价/历史价时，发布失败并列出全部 ID。零值保留为有效值，不被视为空。字段尚未完整的真实商品不会因仅缺一项就被删除。

专用 `scripts/clean_non_goods.py --public <目录>` 先在临时目录重放发布、去重、分片与门禁，并断言结果等于“原列表仅剔除指定六 ID”，包含重复行顺序与全部字段。任何额外新增、删除或字段变更都会失败，验证后才复制产物。
