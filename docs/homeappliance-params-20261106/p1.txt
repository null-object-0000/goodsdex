安全须知
重要的安全说明
请仔细阅读并妥善保管以供将来参考
警告：如果微波炉门或门封已损坏，则不得再使用，直到经有资格的维修人员修好为止。
警告：除有资格的维修人员外，其他人来执行检修操作都是危险的，包括拆下防止微
波能量泄漏的防护盖等操作。
警告：禁止加热装在密封容器内的液体或其他食物，因为这样有可能发生爆炸。
• 器具打算用于家用和类似用途，例如：
— 在商店、办公室及其他工作环境的员工厨房区；
— 农庄；
— 酒店，汽车旅馆和其他居住环境中由客户使用；
— 仅提供床位和早餐的快捷酒店环境。
• 仅使用适合在微波炉内使用的器皿。
• 微波炉烹调食物和饮料时，不准许使用金属容器。
• 当加热塑料或纸质容器中的食物时，注意观察微波炉，防止有着火的可能。
• 用微波炉加热食物和饮料。烘干食品或衣物，及加热暖垫、拖鞋、海绵、湿布和类
  似物品，可导致受伤、着火或火灾的危险。
• 如发现有烟雾，关掉器具开关或拔掉电源插头，并保持炉门关闭，以抑制火焰蔓延。
• 微波加热饮料可能导致延迟喷溅沸腾，因此取放时应小心谨慎。
• 奶瓶和婴儿食品罐中的食物应经过搅拌或摇动，喂食前应检查瓶内食物的温度，
  避免烫伤。
• 微波炉不能用来加热带壳的蛋类和已煮熟的完整的蛋，因为在用微波加热时，甚
  至在加热之后它们可能会发生爆炸。
• 清洁门封、腔体和邻近部件的细节。
• 宜定期清洁微波炉并清除所有食物残渣。
• 不清洁微波炉会致使器具表面劣化，影响器具的寿命，而且可能会导致危险的情况。
• 不应使用蒸汽清洁器来清洗器具。
• 器具应使用独立的电源插座，并独立放置使用。
• 器具不应放置于橱柜中使用。
• 器具不打算由存在肢体、感官或精神能力缺陷或缺少使用经验和知识的人（包括
  儿童）使用，除非有负责他们安全的人对他们进行与器具使用有关的监督或指导。
• 应照看好儿童，确保他们不玩耍本器具。
• 产品正常工作海拔范围高度为0米-2000米。请勿在海拔超过2000米的地区使用。
• 如果电源软线损坏，为了避免危险，必须由制造商、其服务机构或类似的专业人员
  更换。

• 切勿在微波炉顶部放置任何物件。产品应放置在高于地面85cm的位置，两侧与墙
  壁的距离应不小于5cm，炉背与墙壁的距离应不小于10cm，炉顶与壁柜距离不小

• 清洁门封、腔体和炉门玻璃等部件时请使用柔软的布擦拭，避免损伤部件表面。
• 使用过程中，请将家用电器的电源插头完全插入电源插座中，并保持电源插头与插
  座接触良好。
• 当需要使用延长线电源插座时，请使用符合国家标准要求的延长线电源插座。
• 人员离开现场时，请将电源断开。
• 产品出现异常噪声、异常气味、异常高温或故障时，请立即停止使用，关闭开关，断

• 不应从带插座的灯头上引接电源供给家用电器。
• 延长线电源插座所接家用电器的总额定电流值，不应超过原固定插座或线路的额
  定电流值。
• 本产品不应在易燃易爆物品附近或类似环境中使用。
• 使用者不应自行拆卸家用电器，不应变更内部接线、部件和保护装置。
• 从插座上拔下插头时，不应对电源线施加拉力。
• 使用者不应以普通导电体或超出规定电流容量的熔断体替换家用电器和电源的熔
  断体。
• 使用者不应自行改变低压断路器或剩余电流动作保护器的设定值。
• 在微波炉内仅能使用适合的器皿（参考说明书中“微波炉器皿选择”内容），且保证
  器具与炉腔内壁不碰触。
• 微波炉内无食物时，请不要使用微波炉，以免空载运行损坏微波炉或出现危险。

为了安全使用，注意以下事项：
• 不要将食物覆盖密封加热。
• 在微波炉附近不要放置易燃、可燃物品，微波炉在工作期间，务必随时监控微波炉
  烹调情况，并正确设定烹调时间，因为超时烹调可能引起火灾。
• 不要加热食用油或油炸食物，因为油的温度会变的很高，难以控制。
• 每次使用后，先用湿布再用干布除去喷溅于炉内的食物和油脂，以防引起黑烟或起火。
• 若食物放在一次性容器内加热时，请用户注意微波炉内的情况。

为了避免爆炸和突然沸腾现象，注意以下事项：
• 加热液体食物时，用阔口容器盛装，食物顶部离容器口留够一定空间，以免食物出
  现沸腾溢泻现象。
• 加热如土豆、板栗、红香肠等类似块状食物前，先用刀或者叉穿孔以防爆裂、喷溅。

为了防止玻璃板受损坏，注意以下事项：
• 用水清洗时，应先待玻璃板冷却。
• 切勿放置滚烫食品或者容器于冷却的玻璃板上。

• 不要放冰冷食物或者容器于炽热的玻璃板上。
• 微波炉长时间使用后，底部托盘温度较高，解冻食物需待托盘冷却后进行。

为了安全使用，注意以下事项：
• 煮完食物后或者取出食物时，需戴手套，请勿直接用手拿取，微波炉内温度较高，
  避免烫伤。
• 当爆完爆米花后，把表面的保鲜膜取掉时要小心操作，以免烫伤。
• 微波炉在工作的时候，表面温度会很高，请勿触摸，避免烫伤。
• 任何未经过厂家推荐的附件不可使用。
• 请勿使用微波炉做储存食物用途及烹调以外的目的。
• 请将微波炉摆放在幼儿触碰不到的地方。
• 小心微波辐射。微波炉工作时，其通风口处不可放置任何物品，以免影响微波炉正
  常散热。
• 请勿向产品的孔洞插入大头针、铁丝或其他物品，以免触电、受伤。
• 不能将任何异物塞入炉门联锁开关，这样会导致微波泄漏。
• 切勿将温度计置于微波炉内测量温度。

使用限制
• 微波炉必须平放在通风干燥，无腐蚀性的环境中使用，远离高温及蒸汽。
• 微波炉应该远离电视机、收音机和天线（一般大于5m），否则会产生干扰。
• 微波炉应放置在可方便地插拔电源线的地方，且保证接地良好，万一漏电，可以形
  成电流回路避免触电。
• 要确保在门体关闭情况下操作微波炉。
• 第一次使用微波炉时，由于生产制造过程中可能有残渣或油脂存在于炉腔内，加热
  时可能会有异味，甚至冒白烟，这是正常现象，请参考清洁与保养的方法，对新微
  波炉进行除味。
• 为保证正常使用，请不要撕掉炉门内部的透明胶片。

电源注意事项
• 请仅使用配套提供的交流电源线。
• 在进行维护作业或移动之前，请从交流电源插座上断开交流电源线的连接。
• 请勿过度拧捏、弯曲或扭转交流电源线，否则线芯可能会暴露在外或折断。
• 请勿在任何其他装置上使用所提供的交流电源线。
• 禁止使用交流220V以外的电源，以免造成火灾触电。
• 断开交流电源线连接时，务必手持电源插头部分拔下电源，请勿拉扯交流电源线，
  以免造成触电或短路起火。
• 请勿让儿童单独操作使用，应放置在婴幼儿不能触及的地方，以避免触电、烫伤等
  危险事故发生。

• 请勿使用多头插座，以免造成火灾。

• 因蒸汽和热量会导致墙壁及家具受损、变色、变形，因此使用时请距离墙壁和家具
  30cm以上。
• 放入厨房壁柜等地方使用时，应注意保持通风。

使用
连接电源线后，即可开始使用。

开机和关机
接通电源后，显示屏亮起1秒，1秒后进入待机状态。拔下电源插头即可关机。


连接米家APP
本产品已接入米家，可通过米家APP操控，并与其他产品互联互通。
扫描二维码，下载并安装米家APP，已安装米家APP的用户将直接进入设
备连接页。或在应用商店搜索“米家”，下载并安装米家APP。打开米家APP
首页，在页面右上角点击“+”，根据APP提示方式添加设备。
提示：由于米家APP的升级与更新，实际操作可能与以上描述略有差异，请按照当前
   米家APP内指引进行操作。

Wi-Fi连接
待机状态下，长按“功能”键和“火力”键3秒，进入Wi-Fi设置模式。此时
Wi-Fi指示灯闪烁，用户需通过米家APP进行网络设置，设置成功后

开始烹饪
1. 功能选择

待机状态，按“功能”键、“火力”键或“解冻”键选择需要的工作模式，旋转多功能旋钮调节烹饪时间，按下旋钮开始烹饪。
提示：微波炉在待机状态下，5分钟内未操作，自动进入息屏状态，按任意键唤醒屏幕，进入待机状态。




2. 烹饪中
烹饪中，微波炉内照明灯亮起，此时显示屏显示烹饪时间倒计时。旋转多功能旋钮可以直接调节烹饪时间，并直接
以新的时间继续烹饪。



3. 烹饪暂停
                                                        点按
按下多功能旋钮，烹饪暂停。



4. 烹饪取消

烹饪状态/暂停状态下，短按“取消”键，取消当前烹饪，回到
设备上次停留的界面。



5. 烹饪完成
倒计时结束后，微波炉发出三声提示音，烹饪完成，回到待机状态。

维护与保养
对微波炉进行定期清洁与保养有利于提高微波炉使用寿命。
微波炉使用完毕后，请及时拔出电源插头，不要将产品靠近火源或浸入水中。不要将电源线和插头直接放在外
罩上面，防止外罩余热损坏电源线。
应待微波炉冷却后进行清洁和保养。
不要使用带磨损性的清洁剂、清洁器。

微波炉表面：
将柔软的抹布在温水中浸湿并蘸取适量清洁剂擦拭微波炉表面。
炉门：
用温水浸湿的柔软抹布擦拭门、门窗的两边及邻近的零部件。
控制面板：
在清洁面板时需小心，不要蘸过多水，用一块软布轻轻擦拭。
炉腔：
在每次使用完后，请用软布蘸温水清洁炉腔内部和玻璃板，擦去食物残渣，因为食物残渣有可能会导致局部过热。


提示：
微波炉使用一段时间后，炉内可能会出现异味，采用以下三种方法可以消除：
1. 放置几块柠檬片在炉内，高火力加热 2 ~ 3分钟。
2. 放置一杯红茶在炉内，高火力加热2 ~ 3分钟。
3. 放置一些橘子皮在炉内，高火力加热1分钟。
