## 防复发守门规则与复现

**任何发布器写入商品记录的运营字段，在最终归一之后仍存在即直接失败，禁止推送和 OSS 镜像。** `assert_public_fields` 在替换任何发布文件之前检查已知运营 key 和未归一的英文 key；仅三组显式保护数据豁免。新增采集字段必须先分类：运营字段进入丢弃集合，同义字段进入明确映射并加冲突测试，规格字段保留；禁止模糊匹配或静默择一覆盖。

回归测试覆盖：中英同义键冲突、规格值冲突、缺键并集、品牌/价格/gid/型号差异、三组保护、型号不被截断、运营字段残留失败且不写文件、并集键被破坏时拒绝发布。

```bash
PYTHONPATH=src python3 -m pytest -q -m 'not live'
PYTHONPATH=src python3 scripts/finalize_public.py --public /path/to/candidate/public
python3 scripts/verify_field_normalization.py \
  --before /path/to/before/public --public /path/to/candidate/public \
  --api-module /path/to/spend-good/services/api/src/goods.mjs \
  --output /path/to/validation.json
# 以上全部通过后方可提交并推送 data；推送前检查远端基线未变化。
```

发布产物包含更新后的 goods.json、meta.json、merge-audit.json 和全部确定性分片；原始采集记录不改，现有价格时间序列不改。脚本重复运行后数据幂等；审计记录描述当前运行，不把上轮合并数伪装成本轮合并数。
