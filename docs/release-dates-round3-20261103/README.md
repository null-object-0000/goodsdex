## 官方归档与失败证据

- 大疆：实际读完当前中文媒体中心全部 40 页目录、471 个归档条目，按标题筛出 71 篇 2023 年以来相关原文；另跟进前轮已发现的旧新闻路径。旧 `/cn/newsroom/news/<slug>` 有 HTTP 200 的 400–800 字节 JS 跳转壳；当前 `/cn/media-center/announcements/<slug>` 多数返回 400–500 KB 完整稿。不是“官网没有”，而是旧入口需要跟随脚本指向的新入口。该修正贡献 80 条。只采售价段逐个点名的套装及明确单售的发射器等；没有将包装内所有配件、兼容机型、后续140W套装套用整机日期。Air 3S 普通/带屏遥控器用原始 exact-vid 包装中的 RC-N3/RC 2 和数量核对等价关系。Inspire 3 原文只是计划6月交付，实际只记4月 announcement。
- 富士：中国站目录 p1–p15 本轮 HTTP 200；p8以后目录为空，不声称穷尽更早站点。中国站 11 个精确单机身/镜头新闻稿写出产品与日期，记中国站 announcement，不声称国行开售。XF16-55 II 不匹配旧款，X-HF1/X half 使用原文官方别名；套机不继承。另对 4 个中文 fujifilm-x 产品规格 HTTPS 链接，实测 HTTP 403、Cloudflare `Sorry, you have been blocked`；原库 HTTP 链接还有超时（status=0）。没有称“富士官网无日期”。日本站未作为国行事实导入。
- 小米：当前 `mi.com/about/history` raw HTML 中正文由公开 about_history JSON 组件渲染；浏览器确认同样可见，非隐藏商品参数。年/月结构下明确写出米家压力IH电饭煲（2016-03）和小米AI音箱（2017-07），贡献2条 announcement。未将“小米13系列”等泛称传给具体配置，MIX 2 页面提到2016年的前代 MIX 也没有传给 MIX 2。针对 LLM 族再读10个商品/旧产品页，HTTP 200，未取得目标精确型号自己的日期；当前买页有SPA壳，不能据此断言全站没有。未重扫2242个 hidden ID。
- 惠普：本轮5个京东编号搜索受验证限制；兜底5个型号族的官方商品页面虽可读，日期片段为空，未把CPU代际、年份或同系列其他配置当上市月。

[source-inventory.json](source-inventory.json) / [failed-sources.json](failed-sources.json) 逐请求列状态码、最终地址、网络错误、失败正文片段、hash；evidence/ 同时保留压缩的完整响应字节，不只保存成功源。[大疆目录](dji-archive-discovery.json)、[候选拒绝记录](news-review-decisions.json)、[富士目录](fuji-archive-discovery.json)。失败不能推出“官方没有”；200正文里没有明确目标日期只能表述为本次未取得。

## 型号族 LLM 的预算、结果与门禁

先聚批后调用：四品牌剩余3101行，按品牌＋品类＋精确model串保守聚为 **2904族**，不删除颜色/容量/代际/套装信息。按每30族估计全量需 **97次**；本轮只试 **1次／30族**（惠普5、小米10、大疆10、富士5），没有全量，也没有自动重试。族内每个variant保留精确ID，不向族内所有配置自动传播。

实际请求前的最终预算输入约 16053 tokens（启发式估计；UTF-8字节保守上界 37726），输出上限6000。较最初预估增加，来自补入直接来源片段。真实用量 **input 13087 / output 1740 / total 14827**，输出含250 reasoning tokens。网关未暴露币种单价，不虚报人民币成本。模型 flowlet-flash。

结果 `candidates=[]`，30族全部弃答：没有可回指的精确日期句。**没有候选就没有可计算的准确率，不记成0%或100%**；本轮 LLM 不入库、不展示。此前40条已通过审阅的Apple LLM全集、hash和门禁完全不改。仍沿用30个独立型号族抽样、<90%禁用、90–97%仅内部参考、≥97%可作事实但仍标llm。此次未到放行阶段。

## 展示与仍缺

- 本轮93条均可按 `release.label`＋`release.display` 展示：79条为“发售时间”，14条为“发布时间”。都标 `source=official`、`usage=fact`。富士的11条只展示发布时间，不写开售时间。
- 全库507条真源中31条是既有Apple未来计划，保留“预计发售／官方计划”和 reference，不当已开售事实。其余476条真源为fact。既有40条LLM保留llm来源与“推断”标识，不能伪装官方。
- 内部参考：本轮京东候选、弃答族、未通过身份/日期审核的发现队列；前轮16个hidden节点仍禁用，日本/全球日期不拿来展示国行。本轮没有新增可展示的LLM或hidden。
- 仍无日期3421行，包括全部218条惠普。接口不生成release空壳，也不写某年某月占位。本仓库交付的是API/数据元信息；这里说明的是字段展示资格，没有声称修改或截图验证另一个项目的客户端界面。

**本轮可验证公开源覆盖约13.79%，不是已证明的公开源理论上限。** 三路实测后仍有大缺口；京东被验证/403挡住，官方归档更多覆盖整机而非后续套装/耗材，LLM不能补造原文。71篇近期DJI相关稿、富士当前档案和30族试验的范围是有限的，不能将这轮检索范围写成“互联网再无来源”。
